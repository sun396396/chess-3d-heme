# 🦉 Godot 3D 西洋棋 - 嘿美版雛型

## 安裝 Godot 4（30秒搞定）

1. 開啟瀏覽器：https://godotengine.org/download
2. 下載 **Godot 4.x Standard** for macOS（.zip 直接解壓縮即可，不用安裝）
3. 雙擊 `Godot.app` 開啟

---

## 建立新專案

1. 點 **New Project**
2. 選 **3D**（很重要！不要選錯！）
3. 專案名稱打 `chess_3d_heme`
4. 路徑隨意
5. 建立完成

---

## 匯入本喵準備好的檔案

把這個資料夾裡的所有檔案：
- `Main.tscn`     → 拖進 Godot 的 FileSystem 面板
- `Board3D.gd`    → 拖進去
- `ChessLogic.gd` → 拖進去（從 Python 移植過來的棋規）

---

## 操作方式

- **左鍵點擊**：選取棋子（會發光）
- **左鍵再點**：移動到目標格
- **空白鍵**：旋轉視角
- **ESC**：取消選取
